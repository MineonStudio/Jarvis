# Mac 机型年份

按 Apple 官方机型识别文档提取标识符、发布年份和订货号前缀，2026-11-06 更新。共 155 个机型标识符，覆盖全部 Mac 产品系列（含 MacBook Neo）。此表随应用打包，不需要联网查询，也不使用序列号。

同一标识符对应多个年份时，优先用系统报告中的 model_number 匹配订货号；缺失或无法区分时显示全部候选年份，不根据芯片、设备图标或生产日期猜测发布年份。未收录的新机型显示“年份待识别”。后续更新需重新核对以下官方来源，保留同码多年的全部记录。
