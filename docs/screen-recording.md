# 屏幕录制

在侧边栏选择「屏幕录制」查看历史，从菜单栏的「屏幕录制…」开始新录制；没有历史时也可点击页面内的「新建录制」。工具栏左侧为截图同款时间筛选器，右侧提供宫格缩放以及查看、复制、删除组合操作；单击宫格选择视频后可操作，不提供编辑按钮。默认 F2 打开桌面底部的悬浮操作栏，点击「录制」开始，录制期间按 F2 停止；倒计时期间按 F2 取消。可在「设置 → 快捷键 → 屏幕录制快捷键」中修改；录制中也可通过系统菜单栏停止。

## 录制范围

- 全屏：选择全屏模式，点击「录制」开始。
- 窗口：进入桌面窗口选择，一级操作栏保持显示，移动鼠标高亮窗口，点击选中后保留窗口四角标记，Esc 取消；复用截图模块的窗口识别与坐标转换。窗口被遮挡时仍录制该窗口；窗口不可见时暂停，恢复窗口后自动继续，关闭时结束并保存。
- 自定义区域：点击区域模式后直接在桌面拖拽框选，选择过程中保留一级操作栏，松开鼠标确认，保留四角标记。按住 Shift 创建 16:9 选区，Esc 取消。不再显示二级操作栏。

## 声音与画质

默认系统声音开启、麦克风关闭，使用 MP4 / H.264 / SDR、1080p 上限、30fps。可改为 720p 上限、原始分辨率、60fps 或 HEVC 编码。输出保持比例，不放大小区域，编码尺寸对齐为偶数。

系统声音和麦克风可独立关闭或同时开启。开启麦克风后可选择输入设备。窗口模式中的「系统声音」也是系统输出声音，不只限于所选窗口。

首次需要屏幕录制权限；仅开启麦克风时才请求麦克风权限。授权后刷新目标；系统若要求重新打开应用，完成后再试。

## 控制与保存

开始前默认倒计时 3 秒，可在「选项」菜单中选择无、3 秒或 5 秒。录制按钮按「录制＋计时器图标＋秒数」显示选中的延时，无延时时只显示「录制」。点击后操作栏切换为范围摘要、实时倒计时按钮和取消按钮；全屏只显示图标，窗口显示图标与 App 名称，区域显示图标与尺寸。倒计时栏按内容宽度收缩，长名称有最大宽度限制，并保持水平中心位置。倒计时期间可点击取消、按 F2 或 Esc 取消，结束后操作栏隐藏并开始采集。录制期间不显示悬浮控制条或历史页控制条，仅通过 F2 或系统菜单栏的「停止屏幕录制」结束；系统菜单栏显示录制状态。

Jarvis 主窗口在开始前隐藏。自身界面、选区边框不写入全屏或区域录制的成片。关闭主窗口不会停止录制。主动退出时会要求停止并保存；保存失败会取消退出，保留片段供恢复。

新录制固定保存在 Jarvis 数据目录下的 `ScreenRecordings/Videos`，与截图、剪贴板使用同一数据根目录；开发版使用独立的 Jarvis-Dev 数据目录。不提供保存目录设置，已有视频仍按原路径读取。历史卡片隐藏名称，左下角显示录制时长，右下角显示录制时间；悬停时缩略图轻微放大，并淡入显示「播放」「复制」按钮；点击选择后的边框、宫格间距和过渡动画与截图模块一致。最小两档宫格禁用悬浮放大，并遵循系统「减少动态效果」设置。双击或点击「播放」「查看」使用系统原生播放器，默认静音，按视频实际比例显示，只展示视频与系统播放控件；与截图大图相同，支持滚轮缩放，不限制在固定播放器区域内。按 Esc 或点击视频外侧退出。剪贴板的视频也使用同一套预览。右键支持重命名、在 Finder 中显示、复制文件、系统分享和删除。视频删除时移到废纸篓，元数据与恢复片段会删除。已移动的文件可通过右键菜单重新定位。

## 恢复与边界

录制会定期封装约一分钟的临时片段，暂停也会封装片段，最终停止后合并输出单个 MP4。系统中断或异常退出后，历史页列出未完成会话，可「恢复」或「另存恢复」。只能恢复成功封装的部分，未封装的末尾可能丢失。正常保存遇到坏片段时不会静默丢弃，而会保留源数据并提示恢复。

目标路径已经有文件时不会覆盖或将它误认成恢复结果。请选择新文件名另存恢复；已经输出的文件可以单独查看。

首版同时只允许一个屏幕录制会话，与会议录音互斥。锁屏、系统休眠、显示器断开或采集异常会结束本次录制并尝试保存。暂停恢复和定期分段会重新启动采集，分段边界可能有短暂采集间隙。受保护内容由系统限制采集。

窗口选择已支持桌面悬停点选。准备阶段麦克风电平、摄像头画中画、字幕及剪辑留待后续。30 分钟持续录制、复杂跨屏/跨空间操作、蓝牙设备切换仍需专项真机验收。

## 验证入口

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
swift test --scratch-path /Users/Shared/Jarvis/SwiftPM --filter ScreenRecordingTests -Xswiftc -warnings-as-errors
./script/build_and_run.sh --verify
```

测试覆盖多段视频与音轨合并、连续输出时长、Retina/竖屏尺寸、选区坐标、独立元数据、失败恢复保留源文件、成功恢复提交顺序和避免覆盖已有文件。真机已观察到窗口录制生成可播放的 MP4。上述自动化检查不替代长时和外设测试。

F2 操作栏包含全屏、窗口、自定义区域按钮、选项菜单和录制按钮，Esc 退出准备。窗口模式在桌面悬浮高亮选择，区域模式进入框选；选项包含计时器、麦克风、MP4 编码与画质/帧率、鼠标及点按显示、系统音频。

区域拖拽后直接返回一级操作栏，保留录制区域四角；切换其他模式或退出准备时移除。

计时器与麦克风使用原生单选勾选标记，麦克风默认选择「无」。框选只用于当前准备过程；每次点击框选都从空白开始，切换模式、退出准备、取消或结束录制后清空选区。

系统声音使用独立的全局音频采集流，窗口、全屏和区域三种模式都能录入其他 App（例如后台音乐播放器）的输出。画面过滤仅影响视频；音频按采集时间戳与各视频片段对齐，再与可选麦克风轨混音。音频片段缺失或采集失败会提示异常，已封装的片段保留供恢复。
