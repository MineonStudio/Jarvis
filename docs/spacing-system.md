# 界面间距规范

共享定义位于 `Sources/JarvisDesignSystem/JarvisSpacing.swift`。Jarvis 和独立编译的 LANTransfer 使用同一份定义。

| 用途 | 间距（pt） |
| --- | ---: |
| 极小控件缝隙 | 2 |
| 标题和辅助文字 | 4 |
| 图标和短标签 | 6 |
| 相关控件 | 8 |
| 列表项、宫格、并列面板 | 12 |
| 卡片、面板内边距及表单分组 | 16 |
| 独立内容分区 | 20 |
| 页面边距、弹窗内容 | 24 |
| 大分区、首页展示 | 32 / 40 |

布局规则：外层拥有页面或面板边距，子组件只拥有自身内容边距；相邻面板的缝隙由父容器负责。工具栏上边和正文首项上边的距离都由原生工具栏提供，正文不再叠加顶部内边距；滚动区域的底部留白放在滚动内容中，末项可以完整露出。固定高度的原生工具栏图标组只加横向内边距，避免把 32pt 按钮挤进更小的高度。

本次检查和处理范围：

- 首页、侧栏、权限引导、提示消息。
- 截图、录屏、剪贴板与桌面壁纸的历史宫格、元信息、空状态、操作区及滚动边距（顶部不叠加，底部保留 12pt）。
- 简历模板选择、编辑表单、文件名栏、预览画布；移除预览顶部单独的 72pt 留白，补齐纸张底部留白。
- 会议列表、详情、待办、录音及模型提示，统一分栏距离，去掉提示条与页面重复计算的外边距。
- 局域网连接、发送区、任务卡片与引导，移除连接区和发送区在面板边距之内重复增加的内边距。
- AI 聚合、娱乐广场的本地工具栏、下载弹窗、下载任务行。
- 游戏广场、麻将启动菜单、联机房间、资料、数据、签到、声音和牌桌主题设置。
- 设置的全部分区、API 配置、缓存、壁纸源和翻译语言包；语言包行补足上下内边距，下载与错误状态的多个控件改为横向排列，避免 ZStack 将它们叠放。
- 窗口排布卡片的间距与最小宽度计算同步，补齐文本到快捷键之间的距离。

刻意保留的专用几何：

- 正文和工具栏首项统一使用 8pt 侧栏间距，与工具栏上下留白一致；历史画廊继续按工具栏实际位置测量左右边距。
- 分段胶囊按容器高度和选项高度计算的等宽内边距，及截图、录屏悬浮工具栏的窗口安全区。
- 简历 A4 页面、PDF 导出、模板缩略图内部的印刷排版。
- 麻将牌面、手牌、弃牌和场景投影的尺寸、负间距；首页吉祥物与图标的绘制几何。
- 第三方网页内部的布局。

这些数值服务于几何、排版或外部网页，不能机械地取整成通用界面间距。

主窗口工具栏首项统一使用 AI 聚合的 navigation 位置及 36pt 表面高度。普通按钮的 32pt 内容四边补 2pt 后绘制同一层表面，关闭原生重复背景，避免原生按钮与自绘分段控件的左侧留白不同。没有操作的模块保留相同行高的透明占位；正文外层只计算一次侧栏间距。

工具栏首项的 8pt 左边距包含原生 navigation 槽自带的 5pt，统一外层只补足 3pt；补偿放在玻璃表面之外，正文使用同一 8pt 起点，画廊按实际控件边界测量。

AI 聚合与娱乐广场的网页正文采用水平满铺，左右外边距为 0pt；这两个模块的 toolbar 继续使用统一的 8pt 左边距。

F3 独立剪贴板窗口直接复用 ClipboardView 的筛选、宫格、操作和动画。正文左右固定为 8pt，避免将独立窗口的标题栏按钮占位误算进正文边距；标题和工具栏背景处理与主窗口一致。
